<h1>WEATHER</h1>

<p>A website featuring a highly attractive design and scroll-triggered animations
  , utilizing a real API to fetch weather data and manage authentication , it also includes form 
  validation and preserves data in localStorage upon page refresh.
</p>

<h3>Tools</h3>
<p> html , Css , bootstrap , Jquery  and js</p>
<h3>features</h3>
<ul>
